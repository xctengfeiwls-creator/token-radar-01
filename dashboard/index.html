To the judge

This board covers all 40 protocols on the snapshot's watchlist, plus 160 pre-token protocols below the $50M floor, ranked by an implied value that is computed from the snapshot's own figures — not from a list of names. Each category's multiple is the median market-cap-to-TVL ratio of that category's protocols whose token already trades, shrunk toward the global median; growth and age adjust it from there. The formula, the calibration table and the exclusions are in the methodology section below the board. Every farm plan is generated by the same code that wrote board.json, so the page, the board and the screenshots agree. Protocols whose token already trades are set aside in the Live token tab, with their market caps shown as facts, never as model values. The snapshot records no token for a protocol; that is the record, never proof it has none. Implied value is this entry's own claim, not a price.

Token Radar, model radar-2. Snapshot: the DefiLlama protocol index, 2026-11-14. Deterministic: the same snapshot in, the same board out. No network: every byte on this page is in its data file.
