How this entry meets the five criteria. (1) Working radar: 40 of 40 watchlist protocols covered, 200 rows scored, 3 screenshots of the same dashboard this code builds; the page recomputes every row from the model and says when it disagrees with board.json. (2) Value model: implied = TVL x category multiple x growth x maturity, where each multiple is the median market-cap-to-TVL ratio of that category's protocols whose token already trades, shrunk toward the global median — the formula and a 34-row calibration table are in the methodology below the board. No protocol name is special-cased. (3) Farm plans: 6 steps per protocol, each with a cost and a time, plus a totals line, all derived from the protocol's category, chains, TVL and age. (4) Usable: sortable by rank, name, TVL, 7d, age and implied value; filterable by search, category, chain and watchlist-only; a detail view for every protocol, with its model inputs and farm plan. (5) Made, not pasted: one palette (paper, ink, deep teal), one serif/sans type pair, no framework, no network — every byte on the page is in its data file. Protocols whose token already trades are set aside in the Live token tab, with their market caps shown as facts, never as model values. The snapshot records no token for a protocol; that is the record, never proof it has none. Implied value is this entry's own claim, not a price.
